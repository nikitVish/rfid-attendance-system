# RFID Attendance System

An advanced RFID-based attendance management system built using:

- WordPress Plugin Architecture
- ESP8266 / NodeMCU
- REST API
- RFID Scanners
- Real-time Attendance Logs
- Timetable Management
- Teacher & Student Tracking

## Features

- RFID Tap Logging
- Attendance Analytics
- Timetable Integration
- REST API Support
- Device Management
- Role-based Permissions
- Admin Dashboard

## Tech Stack

- PHP
- JavaScript
- WordPress
- ESP8266
- MySQL
